## Purpose

Test repeated consumer episodes where preserved history can constrain later
admissibility.

## Operational L₀ Learning Definition

LEARNING :=
a later episode produces a different justified result for the same request
because specific verified evidence preserved from an earlier episode is
available.

This is a research definition for the probe. It is NOT a universal definition
of learning.

## Firewalls

- history ≠ authority
- unresolved ≠ false
- status ≠ evidence
- more history ≠ stronger evidence
- retrieval not implemented
- proof search not implemented
- no weights/confidence
- no automatic evaluator
- no action layer
- no generic Learning API
- no substrate modification

## Preceding Boundary

This programme begins after:

**C₂₅ CURRENT CONSUMER FRONTIER SATURATED UNDER TESTED EVIDENCE.**

That result does NOT establish logical or mathematical completeness.

It establishes:

no currently identified concrete untested consumer requirement justifies
further speculative consumer-shape probing.

The learning consumer programme addresses a new temporal consumer behaviour:

PAST VERIFIED INFORMATION  
→ AVAILABLE IN LATER EPISODE  
→ MAY CHANGE LATER ADMISSIBILITY.
