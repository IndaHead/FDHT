# FDHT Research Evidence

This directory preserves experimental and audit evidence separately from permanent FDHT mathematics.

## Structure

- `probes/` — experimental Lean artefacts, including successful and failed probes
- `adversarial/` — countermodels and falsification/boundary tests
- `results/` — audit, disposition and closure records

## Firewall

```
PROBE ≠ PERMANENT MATHEMATICS
PASSING PROBE ≠ PUBLIC API
FAILED PROBE ≠ USELESS
UNPROVED ≠ REFUTED
HISTORICAL ARTEFACT ≠ CURRENT DEPENDENCY
PROMOTION REQUIRES A SEPARATE VERIFIED BOUNDARY
```

Permanent FDHT mathematics lives under `fdht/`.
